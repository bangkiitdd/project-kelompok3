Tentang Program Studi

Program Studi D3 Teknik Informatika membekali mahasiswa dengan keterampilan terapan agar siap bekerja sebagai tenaga ahli madya di bidang teknologi informasi. Pembelajaran didominasi praktik di laboratorium dan diakhiri dengan magang di industri.

Mengapa Memilih Kami

Praktik Langsung

Sebagian besar pertemuan berupa praktikum di laboratorium komputer.

Kerja Tim

Mahasiswa terbiasa memakai Git dan GitHub untuk mengerjakan project bersama.

Siap Industri

Kurikulum disusun bersama mitra industri dan diakhiri magang.
